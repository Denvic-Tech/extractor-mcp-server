# Сегментация API 3.2.0

Поддерживается Экстрактор 1С начиная с 3.16.1.xx. `segmentation` - массив группировок, а не объект с `mode`. Каждая группировка содержит обязательные `field`, `segment`, `regular`, `extended`, `initialization`.

```json
{
  "segmentation": [
    {"field":"Регистратор","segment":"По значению","regular":true,"extended":false,"initialization":false},
    {"field":"Период","segment":"День","regular":false,"extended":true,"initialization":false},
    {"field":"Период","segment":"Месяц","regular":false,"extended":false,"initialization":true}
  ]
}
```

`field` - непустой подтверждённый путь поля; для табличной части документа дата шапки задаётся явно как `Ссылка.Дата`. `segment`: `По значению`, `Первая буква`, `Первые две буквы`, `Произвольная подстрока`, `Час`, `День`, `Неделя`, `Месяц`, `Квартал`, `Полугодие`, `Год`. Проверяй соответствие функции типу поля в preview. Дополнительные настройки функции, которые не представлены контрактом, через этот запрос не задаются.

Три признака ролей имеют тип Boolean; у каждого элемента хотя бы один равен `true`. Одна группировка может участвовать в нескольких ролях. Массив содержит до 500 элементов; пустой массив явно не задаёт группировки. Не смешивай массив с `segment`/`segmentField`. Простой одно-сегментный запрос остаётся отдельным вариантом; новые многоролевые запросы формируй массивом. Объект `segmentation` с `mode` отклоняется.

Если пользователь ещё не выбрал сегмент партицирования, согласуй его до preview: документ - день или ссылка; справочник - префикс наименования/кода или ссылка. Для ссылки используй `По значению`, поле `Ссылка` и `maxItemsPerBatch: 1000`; это размер упаковки, а не предел всей выгрузки. Для дня документа проверь `Дата`/`Период`; для табличной части - `Ссылка.Дата`. Поля с одинаковыми путём и функцией могут участвовать в нескольких ролях через один элемент с несколькими флагами.

Хранение в текущем Экстракторе использует `ПараметрРегулярный`, `ПараметрРасширенный`, `ПараметрИнициализации`. Развилки хранения для предыдущих выпусков Экстрактора не используются. Роли группировки и галки сопоставления полей - разные представления: сверяй сохранённый источник и маппинг, не выводи роль из одной галки.

`selectedFields` должен сохранить фактические поля всех выбранных ролей, параметры сегмента и нужные GUID-вычисления из preview/get_project_plan. Перед записью сохрани точный `planId`, после записи выполни `verify_project_summary`. Не заменяй вручную настроенные роли простым запросом без согласованного изменения. Создание настроек не инициализирует очередь и не запускает выгрузку. При неопределённом результате сначала проверь операцию и состояние проекта; не повторяй запись с новым `operationId` вслепую.

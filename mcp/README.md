## Назначение

MCP предлагает варианты настроек и ведёт сохраняемый сценарий создания
или изменения проекта. Выборы, операции и задачи доступны после перезапуска.
Сервер возвращает компактные сводки, результаты проверки и короткие токены
состояния с защитой от конкурентных изменений.

Помощник Экстрактора выполняет маппинг, подбирает типы полей
и создаёт таблицу или топик приёмника. MCP вызывает штатные операции
Экстрактора; ИИ-клиент работает с готовыми вариантами и результатами.

Версия MCP - **3.3.9**, ожидаемый контракт EPA_Projects - **3.3.5**.
Поддерживается Экстрактор **3.16.1.34+**, для маршрута `dcc` - **DCC 2.0.2+**.
Проверяйте фактическую версию методов и capabilities базы через `readiness`.

После подключения прочитайте `list_skills` и применимые документы
через `get_skill`; затем выберите базу через `list_bases`
и проверьте её через `readiness`.

# Один проект для нескольких источников

Проект может содержать несколько строк с отдельными источниками, таблицами
назначения, полями и сегментацией. Подключение задаётся для всего проекта.

1. Вызовите `list_bases`, выберите базу и проверьте `readiness`.
2. Выберите подключение и подтвердите метаданные каждого источника.
3. Подготовьте определение проекта с `projectName`, `connectionName` и `rows`.
   В каждой строке задайте источник, таблицу, поля и массив `segmentation`.
4. Для SQL при capability `direct_sql_operations` передайте определение
   в `create_project` с новым UUID `operation_id`. Для Kafka, AMQP и 1С Шины
   сначала получите план через `preview_project`, прочитайте все его страницы
   и передайте `plan_id` в разрешённую операцию создания.
5. Прочитайте `verify_project_summary` и проверьте каждую строку:
   таблицу назначения, выбранные поля, типы GUID и роли сегментации.

Создание настроек проекта, инициализация очереди и запуск выгрузки - отдельные
операции. Выполняйте только согласованные действия.

При добавлении источников в существующий проект используйте `update_project`
со свежим `expectedState` и сохранённым подключением проекта. Добавляйте строки
по одной и проверяйте результат после каждой записи.

При неопределённом результате сначала проверьте исходную операцию
через `get_operation_status` и перечитайте проект. Не повторяйте запись
с новым идентификатором до выяснения состояния. Создание SQL-таблиц и запись
проекта в 1С не являются одной атомарной операцией.

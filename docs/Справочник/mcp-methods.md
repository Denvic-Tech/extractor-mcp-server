# Методы MCP

Фактически доступные инструменты показывает `tools/list` подключённого сервера.
Перед работой с базой вызовите `list_bases` и передавайте выбранный `base_id`
во все относящиеся к ней вызовы. Возможности методов 1С проверяются через `readiness`.

| Группа | Метод | Назначение |
|---|---|---|
| Подключение | `list_bases` | Список настроенных прямых баз или доступных совместимых коннекторов DCC. |
| Подключение | `health` | Проверка настроек MCP без проверки соединения с 1С. |
| Подключение | `readiness` | Проверка доступа к API 1С, версий, capabilities и хранилища операций. Не проверяет доступ из 1С к приёмнику. |
| Инструкции | `list_skills` | Каталог встроенных и пользовательских навыков и их документов. |
| Инструкции | `get_skill` | Чтение навыка или выбранного справочного документа. |
| Метаданные | `list_metadata` | Полный список объектов метаданных; для выборочного чтения удобнее `search_metadata`. |
| Метаданные | `get_metadata_snapshot` | Сведения о снимке метаданных DCC для согласованного чтения страниц и подготовки планов. |
| Метаданные | `search_metadata` | Поиск объектов по имени и виду с постраничной выдачей. |
| Метаданные | `describe_object` | Полное описание полей объекта метаданных. |
| Метаданные | `describe_object_fields` | Отфильтрованная страница полей, типов и ссылочных целей; в DCC учитывайте дату и предупреждения снимка. |
| Метаданные | `analyze_reference_graph` | Исходящие ссылки, пути связанных объектов, табличные части, циклы и подсказки соединений. |
| Проекты | `list_connections` | Настроенные в 1С подключения к приёмникам всех типов. |
| Проекты | `list_projects` | Имена проектов выгрузки выбранной базы; GUID читать из `projectRef` в проверке проекта. |
| Проекты | `verify_project` | Полные настройки проекта и токен состояния для изменения. |
| Проекты | `verify_project_summary` | Краткое описание проекта без большого токена состояния. |
| Проекты | `preview_project` | Проверка создания проекта или изменения его строк с выдачей плана. |
| Проекты | `preview_project_properties` | Проверка изменения свойств проекта с привязкой к его состоянию. |
| Проекты | `get_project_plan` | Чтение подготовленного плана и страниц его полей. |
| Проекты | `create_project` | Создание настроек проекта по плану или в поддерживаемом прямом SQL-режиме. Не запускает выгрузку. |
| Проекты | `update_project` | Применение изменения по плану или в прямом SQL-режиме; `fieldChanges` требует capability `field_mapping`. |
| Шаблоны | `get_project_template_schema` | JSON Schema запросов шаблона проекта без обращения к базе. |
| Шаблоны | `validate_project_template` | Проверка структуры и семантики шаблона без проверки метаданных и приёмника. |
| Шаблоны | `preview_project_template` | Проверка шаблона в выбранной 1С и подготовка обычного плана создания. |
| Инициализация | `preview_project_initialization` | Проверка строк, обработчиков и последствий инициализации очереди. |
| Инициализация | `initialize_project_queue` | Штатная инициализация очереди по плану или GUID проекта в прямом SQL-режиме. |
| Выгрузка | `preview_project_export` | Проверка немедленного запуска всего проекта без выполнения выгрузки. |
| Выгрузка | `start_project_export` | Запуск всего проекта по плану или GUID в прямом SQL-режиме; возвращает сведения о задаче. |
| Выгрузка | `get_project_export_status` | Статус конкретной задачи выгрузки/инициализации по `task_id`; без него — последняя выгрузка. |
| Остановка | `preview_project_export_cancellation` | Проверка возможности остановки конкретной задачи и подготовка плана. |
| Остановка | `cancel_project_export` | Запрос согласованной остановки задачи; принятие запроса не означает её завершения. |
| Расписание | `get_project_schedule` | Фактическое расписание, активность, часовой контекст и блокировки. |
| Расписание | `preview_project_schedule` | Проверка настройки, включения или приостановки расписания. |
| Расписание | `set_project_schedule` | Применение плана расписания; включение может запустить выгрузку. |
| Контроль | `inspect_project_receiver` | Чтение схемы, количества строк или ограниченной выборки приёмника сохранённой строки проекта через 1С. |
| Контроль | `get_operation_status` | Статус операции записи или запроса запуска без повторения действия. Не заменяет статус задачи выгрузки. |

Прямые SQL-операции доступны при capability `direct_sql_operations` и поддержке
прямых аргументов подключённым MCP. Для Kafka, AMQP и 1С Шины требуется preview
и его `plan_id`. Для записи нужен уникальный UUID `operation_id`; при неопределённом
результате проверяйте исходную операцию, не повторяйте действие с новым ID.
Создание проекта, инициализация очереди, запуск выгрузки и включение расписания —
отдельные действия. Чтение приёмника само по себе не подтверждает равенство источнику;
`typeComparison:"unknown"` не подтверждает совпадение типов. Статус `idle` без
`taskId` не означает успешно завершённую выгрузку.

# Цены номенклатуры: СрезПоследних

Для получения цен на дату используйте доступный в метаданных источник
`РегистрСведений.ЦеныНоменклатуры.СрезПоследних`.
Название регистра и состав измерений подтвердите в выбранной базе.

1. Выберите базу через `list_bases` и проверьте `readiness`.
2. Найдите регистр через `search_metadata` и прочитайте поля
   через `describe_object_fields`.
3. Выберите подключение к приёмнику. Согласуйте поля и режим получения цен.
4. Для сегментации по периоду первым вариантом используйте **Месяц**.
   Существующие настройки проекта сохраняйте. При больших месячных сегментах
   согласуйте дополнительное поле сегментации по фактическим метаданным.
5. Создайте проект в соответствии с типом приёмника и проверьте сохранённые
   настройки через `verify_project_summary`.

Инициализация очереди и выгрузка запускаются отдельно. После запуска читайте
`get_project_export_status` с возвращённым `taskId`.

# Пользовательские навыки

Администратор установки MCP может добавлять собственные навыки в `mcp/skills/.user-skills/`.
Каждый навык хранится в отдельной подпапке с файлом `SKILL.md` в кодировке UTF-8.

```text
mcp/skills/.user-skills/
  company-rules/
    SKILL.md
    references/
      export-rules.md
```

Пример `company-rules/SKILL.md`:

```markdown
---
name: company-rules
description: Правила подготовки выгрузок в компании.
---

# Правила подготовки выгрузок

Применяй эти инструкции при подготовке проектов выгрузки для компании.
Подробные правила находятся в references/export-rules.md.
```

`list_skills` возвращает встроенные и пользовательские навыки вместе.
ID определяется путём относительно `mcp/skills`, а не полем `name`:
для примера это `.user-skills/company-rules`.
Поле `description` в заголовке записывайте в одну строку.
В `documents` перечисляются `SKILL.md` и остальные Markdown-файлы навыка.
Подпапка без `SKILL.md` навыком не считается.

Вызовы MCP (`tools/call`):

```json
{"name": "list_skills", "arguments": {}}
```

```json
{"name": "get_skill", "arguments": {"skill_id": ".user-skills/company-rules"}}
```

```json
{"name": "get_skill", "arguments": {"skill_id": ".user-skills/company-rules", "document": "references/export-rules.md"}}
```

Если `document` пропущен, возвращается `SKILL.md`. Для дополнительных документов
используйте точные пути из `documents`, с `/` в качестве разделителя.
Чтение файлов вне каталога навыка не допускается.

Каталог перечитывается при каждом вызове: добавление, изменение и удаление
файлов не требуют перезапуска MCP. Это работает одинаково при доступе к 1С
напрямую и через DCC: файлы читает сам MCP-сервер.
Навык передаёт инструкции клиенту ИИ; он не добавляет новые MCP-методы
и не запускает код на сервере.

## Docker

В поставляемых Compose-файлах папка подключена с хоста только для чтения:

```yaml
volumes:
  - ./skills/.user-skills:/app/mcp/skills/.user-skills:ro
```

Путь слева задаётся относительно Compose-файла в `mcp/`.
Администратор изменяет файлы на хосте; MCP читает их внутри контейнера.
При собственной конфигурации Compose добавьте такое подключение и пересоздайте
контейнер. После подключения изменения навыков доступны без пересборки образа.
Сохраняйте папку хоста при обновлении установки.

Все клиенты с доступом к этой установке MCP могут читать опубликованные навыки.
Не размещайте здесь пароли, токены и другие секреты.

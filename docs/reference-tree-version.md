# Дерево связей и версия API 3.2.0

`analyze_reference_graph` возвращает дерево подтверждённых ссылок метаданных. При `account_scope` назначенные виды субконто читаются в 1С; через DCC это выполняется задачей со структурированным результатом. Типы метаданных не доказывают использование значений в движениях.

Подробности: [описание дерева](../mcp/skills/extractor1c/references/17-reference-tree.md). MCP и EPA_Projects: 3.2.0; Экстрактор: начиная с 3.16.1.xx. Версия опубликованных методов читается из readiness. [Массив сегментации](project-segments.md) одинаков для HTTP и DCC.

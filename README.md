# MCP Экстрактора 1С

MCP подключает ИИ-клиенты к **Экстрактору 1С в BI**: позволяет читать метаданные,
создавать и проверять проекты, запускать выгрузку, управлять расписанием
и читать результаты в приёмнике.

**Разработчик — Денвик Аналитика, ООО.** [Сайт продукта](https://bi.denvic.ru/)
· [Документация Экстрактора](https://docs.denvic.tech/extractor_docs/extractor_docs/)

## Совместимость

- MCP **3.3.7**, ожидаемый контракт EPA_Projects **3.3.5**.
- Экстрактор 1С в BI **3.16.1.34 или новее**, с лицензией и актуальными методами.
- Python **3.11+** либо Docker с Compose v2.
- Для маршрута через DCC — **DCC 2.0.2 или новее**.

Обновление MCP не обновляет методы в базе 1С. Фактическую версию и возможности
выбранной базы проверяйте через `readiness`.

## Как это работает

ИИ-клиент получает инструкции через MCP, читает метаданные и помогает настроить
проект выгрузки. MCP передаёт команды Экстрактору выбранной базы и возвращает
состояние операций. Экстрактор выполняет выгрузку из 1С в настроенный приёмник.

```text
ИИ-клиент → MCP → Экстрактор в 1С → Приёмник данных
                 ← Статусы и результаты ←
```

Данные выгружает Экстрактор: MCP управляет проектами, запуском и проверкой
результатов. Для конкретной базы выбирается один из двух маршрутов.

[Техническая схема SVG](docs/diagrams/mcp-deployment.svg)
· [PNG](docs/diagrams/mcp-deployment.png)
· [PlantUML](docs/diagrams/mcp-deployment.puml)

| Маршрут | Как выполняются команды |
| --- | --- |
| `direct_http` | MCP обращается к HTTP-публикации 1С; базы перечислены в `bases.yaml`. |
| `dcc` | MCP ставит задачу в DCC, 1С получает её исходящим обменом и возвращает результат. |

ИИ-клиент подключается к MCP локально через `stdio` либо по HTTP через `/mcp`.
Для внешнего доступа используйте HTTPS и Bearer-токен.

**Напрямую:** MCP размещается там, где доступны web-публикации баз 1С.
Он обращается к HTTP API Экстрактора по адресам из `bases.yaml`.

```text
ИИ-клиент → MCP → Web-публикация 1С → Экстрактор
```

**Через DCC:** MCP должен иметь доступ к DCC. Базы регистрируются в DCC,
а 1С сама инициирует исходящий обмен: забирает задачи и возвращает результаты.
Web-публикация базы для этого маршрута не требуется.

```text
ИИ-клиент → MCP → DCC ← Исходящий обмен из 1С
```

MCP можно запустить локальным Python-процессом или в Docker. Подробности
размещения, сетевых требований и настройки маршрутов — в
[инструкции установки](docs/Справочник/installation.md).

## Быстрый старт

Подготовьте Экстрактор в 1С и выбранный маршрут по [инструкции установки](docs/Справочник/installation.md).
Затем получите репозиторий и запустите установщик:

```text
git clone https://github.com/Denvic-Tech/extractor-mcp-server.git
cd extractor-mcp-server/mcp
```

Windows PowerShell:

```powershell
py -3 scripts/install.py
```

Linux / macOS:

```bash
python3 scripts/install.py
```

Установщик помогает выбрать маршрут и запуск в Python или Docker,
создаёт закрытые настройки и устанавливает зависимости.
Существующие `.env` и `bases.yaml` без явного запроса не заменяются.

После подключения вызовите `list_skills`, прочитайте применимые инструкции
через `get_skill`, затем выполните `list_bases` и `readiness` выбранной базы.
Создание проекта, инициализация и запуск выгрузки выполняются отдельными действиями.
